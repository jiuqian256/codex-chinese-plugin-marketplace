## 中文名称与用法

**中文名称：** 已完成任务绩效表整理

**用途：** 批量整理绩效 Excel，按岗位保留分数，生成完成分和完成率并统一明细格式。

**调用示例：** 使用 $chinese-skills:gongbei-completed-table-modifier 按人员岗位整理这些已完成任务绩效表。

文中的 `<SKILL_DIR>` 指本次加载的 SKILL.md 所在目录；从实际技能路径解析，不假定用户目录、操作系统或插件缓存版本。脚本接收的项目路径和输出路径仍使用当前任务的实际路径。


# 功倍已完成表格修改

将用户给出的任务明细工作簿整理成统一的个人绩效表。用户后续只需提供：

1. 一个或多个“已完成_提交任务（姓名）.xlsx”文件；
2. 一张含“姓名、岗位、当月应做积分”的岗位/目标图；
3. 最终输出文件夹。

## 执行要求

1. 使用 `spreadsheets` 技能及 `@oai/artifact-tool` 处理 `.xlsx`，先检查源表字段、行数和现有公式。
2. 从图片读取人员姓名、岗位和当月应做绩效分。以文件名括号中的姓名匹配图片姓名；岗位含“高级”时使用高级绩效分，含“中级”时使用中级绩效分。无法唯一匹配时，先请用户确认。
3. 每个输出文件保持原文件名，保存至用户指定路径；不要改动源文件。
4. 建立或整理“任务列表”工作表，仅保留以下列，按此顺序输出：
   - 任务标题*
   - 父任务标题
   - 所属项目
   - 所属计划*
   - 执行人
   - 评分明细
   - 高级绩效分或中级绩效分（依岗位选择）
   - 最近100条评论
5. 使用源表同名字段取数；不要按固定列号假设。绩效列选择后保持为数值类型。
6. 清空所有任务数据行（不含表头和汇总行）的“父任务标题”和“评分明细”内容，保留其列和格式。
7. 所有已用行的行高统一为 25；除此以外不调整列宽、颜色、边框、公式或其他内容，除非用户明确要求。

## 汇总区

在任务数据后保留三行汇总，标签位于“评分明细”列，数值位于“绩效分”列：

| 标签 | 值 |
|---|---|
| 当月完成绩效分 | 对任务数据行绩效分求和的公式 |
| 当月应做绩效分 | 从岗位图片读取的该人员目标值 |
| 个人完成率 | `当月完成绩效分 / 当月应做绩效分` 的公式；分母为 0 时显示 0 |

使用 `SUM` 与 `IFERROR`（或等效的零分母保护公式），并将完成率设置为百分比格式。不得清空这三行的标签、目标值或公式。

## 格式与验证

1. 延续源表或用户示例的样式；不要擅自添加图表、额外工作表或说明列。
2. 导出前检查每份表：
   - 姓名、岗位、目标分匹配正确；
   - 仅保留岗位对应的绩效列；
   - 数据行的父任务标题、评分明细为空；
   - 汇总三行及公式仍存在；
   - 无 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或 `#N/A`。
3. 至少渲染抽样的高级和中级各一份表，确认行高、汇总区和列内容可读。
4. 最终回复简要说明已完成，并提供每个输出工作簿的文件引用。
