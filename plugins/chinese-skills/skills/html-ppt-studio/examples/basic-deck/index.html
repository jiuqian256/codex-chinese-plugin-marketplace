html-ppt-studio

像传统 PPT 一样编辑和演示 HTML 内容。

把网页、图片页、PPT 截图或 Agent 生成页面，变成可翻页、可演示、可保存编辑状态的 HTML Deck。

可移植 skillCodex、Hermes、Claude Code、Cursor、OpenCode 或其他文件型 Agent 都可以读取同一套规则。
运行时优先演示和手动小改动可以在浏览器里完成，不必每次都调用模型。
16:9固定舞台，方便预览、截图和导出 PDF。
3三种模式：极速初稿、正式演示、完整编辑。

运行时契约

把内容、运行时、服务和模型分开。

Deck 应该能在浏览器里直接观看。本地服务负责保存和导出，模型主要用于生成和复杂修改。

内容层页面、图表、图片、版式和要传达的信息。
运行时层导航、演示者视图、观众窗口、页面状态和编辑入口。
本地服务写入状态文件，并可选导出截图式 PDF。
0观看静态发布版不需要 API key。
1用于投屏的干净观众窗口。
02 / 03
编辑契约

网页手动编辑必须保存成真实状态。

只改 DOM 不算保存。下一次 Agent 修改 Deck 前，应该先读取保存后的状态文件。

点击编辑页面文字进入浏览器可编辑状态。
点击保存Deck 会把页面顺序、文字、备注和改动页提交给本地服务。
先读状态后续改稿应从 `deck-state.json` 开始，而不是依赖旧 HTML 猜测。
JSONAgent 易读取的简单状态格式。
PDF通过模板服务可选导出截图式 PDF。
