# 基础样例 Deck

这是一个已脱敏的最小 HTML PPT 样例，用来展示 `html-ppt-studio` 的公开运行契约。

它展示：

- 固定 16:9 舞台。
- 键盘翻页。
- 键盘翻页不绑定空格键，避免和文字编辑、中文输入法确认冲突。
- 演示者模式。
- 计时暂停和继续。
- 干净观众窗口。
- 观众窗口全屏入口。
- 简单网页文字编辑。
- 通过本地服务保存到 `deck-state.json`。
- 演示者备注按稳定 `slideId` 自动保存，重新打开后恢复。
- 调用可选 PDF 导出接口。

## 运行

在本目录执行：

```bash
node ../../templates/edit-server/server.js
```

打开：

```text
http://127.0.0.1:8801/
```

## 试用编辑

1. 点击 `编辑`。
2. 修改任意页面文字。
3. 点击 `保存`。
4. 查看 `deck-state.json`。

这个状态文件故意保持简单，方便 Agent 在后续修改 Deck 前读取。

## 试用演示者备注

1. 点击 `演示`。
2. 修改右上角演讲备注。
3. 等待状态提示 `备注已自动保存`，或再次点击 `演示` 关闭演示者视图触发保存。
4. 刷新页面后再次打开 `演示`，备注应从 `deck-state.json` 恢复。
