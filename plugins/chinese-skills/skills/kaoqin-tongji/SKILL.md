## 中文名称与用法

**中文名称：** 个人考勤月度汇总

**用途：** 汇总 Excel 考勤日报中的请假、迟到、加班和周末休息，输出人员统计及明细。

**调用示例：** 使用 $chinese-skills:kaoqin-tongji 汇总这些个人考勤日报，生成月度统计表。

文中的 `<SKILL_DIR>` 指本次加载的 SKILL.md 所在目录；从实际技能路径解析，不假定用户目录、操作系统或插件缓存版本。脚本接收的项目路径和输出路径仍使用当前任务的实际路径。


# 考勤统计

将同一统计周期内的个人考勤日报汇总为可筛选、可审计的 Excel 工作簿。源文件保持只读，不修改原日报。

## 开始前

- 确认输入考勤文件夹；仅处理其中的考勤日报文件，忽略临时文件（如 `~$` 开头的文件）。
- **必须询问用户最终 Excel 的输出路径。** 用户未明确给出路径时，不得推断为源文件夹、当前工作区或默认输出目录。得到路径后再创建工作簿。
- 若目标文件已存在，询问用户是否覆盖，或改用新文件名。

## 统计口径

按人员汇总以下字段：事假、调休、年假、病假、婚假、产假、陪产假、其他、产检假、丧假、迟到时长、加班时长、周六周日休息天数。保留源表中的单位：小时、天或分钟。

- 优先读取日报已汇总的对应统计列，不要从打卡时间重复推算请假、迟到或加班。
- 加班使用日报的“加班时长（小时）”字段。若需要从加班时间段自行计算，跨越 12:30–14:00 的整天加班必须扣除 1.5 小时午休，并在结果中说明该推算口径。
- 周六周日休息天数：仅统计日期为周六或周日、且日报班次明确为“休息”的记录；补班、排班或加班日不计入。
- 所有统计值为 0 的类别仍应在汇总表显示为 0。

## 输出要求

使用 `spreadsheets:Spreadsheets` 技能创建并核验 `.xlsx`。工作簿至少应有：

1. “人员汇总”页：一行一人，列出全部统计类别、单位、合计行和简洁口径说明；汇总数值应通过明细页公式汇总，便于审计。
2. “非零明细”页：每条非零统计记录单独成行，至少包含日期、姓名、类别、数值、单位、原始假勤/加班说明、来源文件和统计口径。周六周日休息记录也须列出。

对源文件数、人员数、非零明细条数做合理性检查；扫描公式错误，并对汇总页和明细页完成视觉核验。完成后只交付用户指定路径中的最终工作簿，说明采用的关键口径。
